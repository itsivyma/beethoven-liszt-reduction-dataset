# References

This directory tracks external sources used by the project without committing copyrighted books, papers, or scanned scores to this public repository.

## Policy

- Store bibliographic metadata, notes, quotations within fair-use limits, and exact citation locations.
- Do not commit full copyrighted PDFs unless redistribution rights are clearly established.
- Local private files may be used in VS Code/Codex workflows if available on the research machine.
- Keep local-only source files outside the public repository or under ignored directories.

## Current known resources

- Samuel Adler, *The Study of Orchestration* (2002): orchestration terminology, instrumental roles, texture, doubling, register, and related analytical concepts.
- METEOR material: previously reviewed as a methodological/data reference, but it is not part of the current primary training dataset.
- Notes from senior student / prior database exploration: useful for historical project context, but not part of the final dataset scope.
